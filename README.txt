Rozetta Brunch — sitio web (landing page)
=========================================

Contenido
  index.html   La página completa (HTML, CSS y JavaScript en un solo archivo)
  img/         Fotos y logo

Cómo publicarlo
  Es un sitio estático: no necesita servidor, base de datos ni compilación.
  Sube la carpeta tal cual (index.html + img/) a cualquier hosting estático:
  Netlify (arrastrar y soltar la carpeta), Vercel, GitHub Pages, Cloudflare Pages,
  o la carpeta public_html de un hosting tradicional.

Dependencias externas
  - Google Fonts (Great Vibes, Pinyon Script, DM Serif Display, Cormorant Garamond, Jost)
  - Enlaces a Instagram y Google Maps
  Nada más.

Pendiente de confirmar con el negocio
  - Horario (por ahora la página remite a Instagram)
  - Número de la dirección en Calle de la Candelaria
  - Precios del menú
  - Fechas del taller de barismo
  - Sección de Navidad: es de temporada; quitarla o esconderla después de las fiestas
    (buscar <!-- TEMPORADA --> en index.html).

Notas
  - Español por defecto, con botón para cambiar a inglés.
  - En móvil (menos de 860px) la navegación es un menú hamburguesa.
